ROSHU APOLOGY WEBSITE — TRUE RUN-CYCLE VERSION

This version uses an SVG character built from separate body parts, with CSS animations on both legs and arms, plus left-to-right entrance movement. It is not a pre-rendered video, but it creates an actual animated run cycle rather than moving a still PNG.

RUN IN VS CODE:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Right-click index.html and choose Open with Live Server.

PUBLISH:
Upload index.html, style.css, script.js, and README.txt to the root of your GitHub repository. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

EDITING:
The apology text is in index.html. Animation timings and colors are in style.css.
